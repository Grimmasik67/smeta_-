# Android-приложение «Затраты» 8.2.0

Автономная оболочка для текущего HTML-приложения. Все файлы включены в APK. Идентификатор `ru.markin.zatraty`, адрес локального хранилища `https://appassets.androidplatform.net/assets/index.html` и ключ подписи должны оставаться прежними при обновлении. Версию `versionCode` нужно увеличивать.

JSON и CSV сохраняются через системный диалог Android. Импорт читает выбранный пользователем документ. Очистка и восстановление базы ждут успешного завершения записи резервной копии; отмена диалога не меняет базу. Браузерная база автоматически не переносится — её нужно выгрузить и загрузить JSON-файлом.

Приложение не запрашивает разрешение на сеть и загружает только включённые файлы. Внешние ссылки, нажатые пользователем, открываются в системном браузере. Требуется Android 8.0+ и обновлённый Android System WebView с поддержкой современных JavaScript API.

## Сборка

Скрипт `build.py` использует JDK 21 и инструменты из Maven: aapt2, R8, apksig и android-all (API 35). Версии и SHA-256 закреплены в `tools.lock.json`. `aapt2` взят из osx-артефакта Google Maven; R8 и apksig — из Google Maven; android-all — из Maven Central (org.robolectric). Инструменты в репозиторий не включены.

Положи их в отдельный каталог, затем:

```sh
python3 native/android/build.py --tools /path/to/tools --signing /private/path/to/signing
```

Ключ обновлений и пароль создаются в закрытом каталоге `--signing`, за пределами Git. Не удаляй их и не публикуй: без прежнего ключа новая версия не установится поверх этой. Скрипт не выводит пароль. В APK входит только публичный сертификат.

После сборки `npm run test:android` проверяет JavaScript-мост на сохранение и отмену. В текущей сборке пройдены 9 проверок моста, компиляция Java/Dex, проверка структуры, выравнивания и APK-подписи v2/v3. На настоящем Android-устройстве и в Android-эмуляторе приложение пока не запускалось; системный выбор файлов и жизненный цикл Activity требуют проверки на телефоне.
