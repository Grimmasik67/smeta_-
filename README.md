# Главбух PRO · 8.0

Простой учёт затрат на объектах: название, контракт, поступления, бюджет и расходы. Приложение работает без сервера и без регистрации.

## Как пользоваться

Открой `index.html` или существующий адрес GitHub Pages. Изменения сохраняются в браузере автоматически. Кнопка «Сохранить» проверяет заполнение расходов. Неназванный черновик восстанавливается после перезапуска. При переходе к другому объекту непустой черновик сохраняется с временным названием.

Для переноса между устройствами: «Выгрузить базу» → передать JSON → «Загрузить базу». Перед импортом и удалением сохраняется прежняя база; вернуть её можно появляющейся кнопкой «Вернуть прежнюю базу». Это обмен файлами, а не общая онлайн-база. При правке одного и того же расхода используется более поздняя дата изменения, поэтому часы устройств должны быть настроены правильно. Для старых файлов без дат приложение запрашивает подтверждение замены совпадающих полей. Отсутствие строки в старом файле не считается удалением.

**Данные принадлежат конкретному браузеру и адресу.** Открытие скачанного файла не переносит данные с GitHub Pages автоматически: сначала выгрузи JSON из прежней версии и загрузи его в новую. Не запускай старую v4.2 параллельно с новой версией: она не поддерживает даты изменений и отметки удаления. Старая ссылка `БухУчет_Тест.html` теперь переводит на актуальное приложение.

«Остаток денег» = поступления − введённые платежи. Процент комиссии и налоговый расчёт показывают резерв; они не изменяют фактические расходы. Расчёт налогов приблизительный, без страховых взносов, региональных льгот и проверки первичных документов. Входной НДС не определяется автоматически по способу оплаты. Значения контракта и поступлений — общие суммы по объекту, отдельного журнала банковских операций нет.

## Исправления 8.0

- Копейки, отрицательные остатки и дробный аванс отображаются корректно; неверный ввод не перезаписывает сохранённую сумму.
- Стабильные идентификаторы и названия старых объектов; автоматическое восстановление последнего объекта и черновика.
- Явная ошибка при отказе сохранения; актуальные данные остаются доступными для выгрузки из открытой страницы.
- Обновление расходов, поступлений и параметров при импорте; отметки удалений защищают от возврата строк из старых копий.
- Проверка структуры импорта, защита описаний и названий от HTML, безопасный CSV с копейками.
- Средняя сумма считается по уникальным расходам; дублирование зарплаты сохраняет сотрудника.
- Сводка, категории и остаток используют одни и те же фактические суммы; снята автоматическая надбавка к самозанятым и наличным платежам.
- Защита независимых правок в двух вкладках, резерв до удаления и импорта, удобное сохранение через Ctrl/Cmd+S.

Уже потерянные или искажённые старой версией названия и суммы автоматически восстановить нельзя: для этого нужен прежний JSON или первичные документы.

## Проверка разработки

Для запуска приложения ничего устанавливать не требуется. Для регрессионных тестов:

```sh
npm install
npx playwright install chromium
npm test
```

Можно использовать установленный Chrome через переменную `CHROME_EXECUTABLE` с полным путём к исполняемому файлу. Тесты запускают отдельный профиль браузера, используют вымышленные записи и не обращаются к рабочим данным. Скриншоты и результаты сохраняются в `.test-results/`.

Проверено 28 сценариев в Chrome, включая экран шириной 390 px. Реальный iPhone и Safari отдельно не проверялись.
