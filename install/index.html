Затраты на объектах

Установка на телефон

Уже ведёшь объекты? Сначала нажми в прежней версии «Выгрузить базу». После установки загрузи этот JSON-файл через «Загрузить базу».

Android

Отдельное приложение. Работает без интернета с первого запуска.

Скачать APK для Android
  1. Скачай и открой APK на телефоне.
  2. Если Android попросит, разреши установку из выбранного браузера или файлового менеджера.
  3. Открой значок «Затраты».

Версия 8.2.0 · Android 8.0 и новее · требуется актуальный Android System WebView.

Для обновления устанавливай новый APK поверх приложения. Перед обновлением выгрузи резервную копию; удалять приложение не нужно.

iPhone

Установка с сайта на главный экран. Открывается по значку в отдельном окне.

Открыть в Safari для установки
  1. Открой сайт в Safari.
  2. Нажми «Поделиться» → «На экран Домой».
  3. Если есть «Открывать как веб-приложение», включи. Затем нажми «Добавить».

Первый раз открой значок «Затраты» с интернетом и дождись сообщения «Готово к работе без интернета».

Если прежние записи не появились, загрузи сохранённый JSON-файл.

Записи хранятся на каждом устройстве отдельно. Для передачи между телефоном и компьютером используй выгрузку и загрузку JSON. Регулярно сохраняй резервную копию базы.
